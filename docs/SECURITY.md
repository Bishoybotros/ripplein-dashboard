# ملاحظات الأمان

## المبدأ
الواجهة **public** بالكامل — أي حد يقدر يقرأ كودها. فأي حاجة سرية مكانها الخادم فقط.

## توزيع الأسرار

| المكان | إيه اللي فيه |
|---|---|
| الواجهة / GitHub | `VITE_API_URL` فقط — مش سر |
| Script Properties | `ADMIN_SECRET`, `ADMIN_SECRET_<USER>`, `SPREADSHEET_ID` |
| Google Sheet | بيانات المشاركين + `pin` — محمي بصلاحيات جوجل، مش بيتشارك |
| المتصفح (localStorage) | توكن جلسة فقط — مفيش كلمات سر |

## المصادقة
- تسجيل الدخول بيرجع توكن عشوائي بيتخزّن في `CacheService` على الخادم لمدة ٦ ساعات، وبيتجدّد مع كل استخدام.
- التوكن بيتلغى فورًا عند الخروج.
- كلمة سر الأدمن بتتبعت مرة واحدة وقت الدخول بس، وبعد كده التوكن بس.
- لو الجلسة انتهت، الرد بيكون `SESSION_EXPIRED` والواجهة بتطلب الدخول تاني.

## التحقق على الخادم
كل طلب كتابة بيمر على:
1. توكن صالح + الدور المطلوب.
2. المشارك موجود ونشط.
3. التصنيف موجود ومفعّل.
4. النقاط رقم صالح ≠ صفر و|القيمة| ≤ 5000.
5. السبب ≤ 300 حرف، وإجابة لحظة الفراشة ≤ 1000 حرف.
6. `isScoringOpen` مفتوح.
7. `LockService` بمهلة ٢٠ ثانية حوالين كل كتابة.

## عزل بيانات المشاركين
`getParticipant` بيتحقق إن `record.id === session.sub` إلا لو الدور أدمن.
تغيير الـ `id` في الرابط بيرجع `FORBIDDEN` — ده مغطّى باختبار في `npm run test:api`.

## قواعد ثابتة
- المشارك **مبيقدرش** يضيف أو يعدّل أو يحذف نقاط. الإجراءات دي كلها `auth_(p, 'admin')`.
- المشارك **مبيقدرش** يغيّر فريقه أو مستواه أو ترتيبه — كلها محسوبة على الخادم.
- مفيش حذف نهائي لأي معاملة. التراجع بيسيب أثر كامل (`reversedAt`, `reversedBy`).

## الخصوصية
- إجابات لحظة الفراشة `private` افتراضيًا. مفيش endpoint عام بيرجّعها إطلاقًا.
- `public` معناها موافقة صريحة على العرض **بدون اسم** — ومسؤولية العرض على فريق التنظيم.
- `getLeaderboard` بيرجّع الاسم ورقم الموظف والفريق والنقاط بس. مفيش تليفون ولا إيميل ولا PIN.
- التأثير السري بيظهر في ملف صاحبه بس — تفاصيله مش بتتعرض على الشاشة.

## حدود معروفة (مقبولة لمؤتمر)
| الحد | التوضيح |
|---|---|
| الـ endpoint مفتوح للقراءة العامة | الرادار معروض على شاشة في القاعة أصلًا |
| `pin` مخزّن كنص في الشيت | مخاطرة منخفضة (٤ أرقام لعرض بيانات شخصية فقط) والشيت خاص. التشفير كان هيمنع الأدمن من مساعدة أي حد نسي رقمه |
| الجلسات في `CacheService` | لو جوجل نضّف الكاش الكل بيسجّل دخول تاني. مفيش فقدان بيانات |
| كلمة سر أدمن مشتركة | استخدم `ADMIN_SECRET_<USERNAME>` لو عايز فصل كامل لكل أدمن |

## لو كلمة السر اتسرّبت
غيّر `ADMIN_SECRET` من Script Properties. بيتفعّل فورًا، وكل التوكنات القديمة بتفضل شغالة لحد ما تنتهي — لو عايز تلغيها حالًا اعمل **Deploy → New version** (بيمسح الكاش).
