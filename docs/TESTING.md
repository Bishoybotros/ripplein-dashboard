# قائمة الاختبار

## آلي
```bash
npm run test:api    # 54 اختبار لمنطق الـ backend
npm run typecheck
npm run build
```

`apps-script/tests/mock.cjs` بيحاكي Google Sheets و Cache و Lock و Properties في الذاكرة، فالاختبارات بتشتغل من غير أي اتصال بجوجل.

### الاختبارات مقسّمة على:
التنصيب · المستويات وحدودها · دخول المشارك · عزل البيانات · دخول الأدمن · إضافة نقاط · التحقق من المدخلات · الخصم · التراجع · صعود المستوى ودخول Top 10 · مجاميع الفرق · لحظة الفراشة · الإعدادات · الجلسات · النقاط العامة.
